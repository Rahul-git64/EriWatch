## Root Cause Analysis & Runbook Documentation
- Docker Desktop on Windows with WSL2 backend failed to bind `\\.\pipe\dockerDesktopLinuxEngine` because `/etc/wsl.conf` set automount root to `/mnt/host`, preventing the backend from resolving `/c/Program Files/...`.
- Injecting the `/c` symlink into the `docker-desktop` distro resolved the bootstrap issue.
- Authored `docs/runbooks/docker-windows.md` detailing the failure mode, the symlink fix, why it is fragile, and the clean startup procedure.
- Added make targets `stack-up`, `stack-down`, and `stack-status` to `Makefile`.
